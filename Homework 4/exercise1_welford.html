Ex. 1 – Welford’s Recurrence Formulas

1. Notation and Knuth’s recurrence for the mean

Given observations x1,…,xk, define the running mean Mk = (1/k)·Σ xi. Since k·Mk = (k−1)·Mk−1 + xk:

Mk = Mk−1 + (xk − Mk−1) / k ,   M0 = 0

Let dk = xk − Mk−1 (the “innovation”). Then two useful identities follow:

Mk − Mk−1 = dk/k   (1)
xk − Mk = dk − dk/k = dk(k−1)/k = (k−1)(Mk − Mk−1)   (2)

2. Derivation of the recurrence for the sum of squares

Let SSk = Σi=1..k (xi − Mk)². Expanding the square gives the computational form

SSk = Σ xi² − k·Mk²

Subtracting the same expression for k−1:

SSk − SSk−1 = xk² − k·Mk² + (k−1)·Mk−1²

Use k·Mk = (k−1)Mk−1 + xk, so k·Mk² = Mk[(k−1)Mk−1 + xk]. Substituting:

SSk − SSk−1 = xk² − xkMk − (k−1)Mk−1(Mk − Mk−1)
= xk(xk − Mk) − (k−1)Mk−1(Mk − Mk−1)

By identity (2), (k−1)(Mk − Mk−1) = xk − Mk, hence

SSk − SSk−1 = (xk − Mk)(xk − Mk−1)

Welford’s recurrence for the sum of squares:

SSk = SSk−1 + (xk − Mk−1)(xk − Mk) = SSk−1 + dk² (k−1)/k ,   SS0 = SS1 = 0

Both terms of the increment have the same sign, so SS never decreases and no catastrophic cancellation occurs (unlike Σx² − kM²).

3. Recurrence for the variance

Sampling (unbiased) variance: sk² = SSk/(k−1) for k ≥ 2 (the biased/population version is SSk/k). Replacing SSk = (k−1)sk² and SSk−1 = (k−2)sk−1² in the recurrence above and dividing by (k−1):

sk² = ((k−2)/(k−1))·sk−1² + (xk − Mk−1)² / k ,   k ≥ 2

For the biased version σ̂k² = SSk/k:   σ̂k² = σ̂k−1² + [ (xk − Mk−1)(xk − Mk) − σ̂k−1² ] / k.

4. Code (core logic = 3 lines)

function welford(data) {
  let M = 0, SS = 0, k = 0;
  for (const x of data) {
    k++;
    const d = x - M;        // 1) innovation  x_k - M_{k-1}
    M  += d / k;            // 2) Knuth: new mean M_k
    SS += d * (x - M);      // 3) Welford: (x_k - M_{k-1})(x_k - M_k)
  }
  return { mean: M, SS, variance: k > 1 ? SS / (k - 1) : 0 };
}
