Exercise 2 – Numerical computation of the normal CDF

Φ(z) = P(Z ≤ z) = ∫−∞z φ(t) dt, with φ(t) = e−t²/2/√(2π).

Reference values and sources. The reference is SciPy's scipy.stats.norm.cdf (documentation). Published outputs found on the web: Φ(1.96) = 0.9750021048517795 (Statology); Φ(−1), Φ(−2.5), 1−Φ(5) and 1−Φ(10) in the SciPy-derived tests of dml-core; CDFLIB (cdflib) agrees on Φ(1.96) and 1−Φ(5). All values in the tables were additionally recomputed independently with Python mpmath.ncdf at 40 digits of working precision and rounded to 17 significant digits. Checked against scipy.stats.norm.cdf (SciPy 1.18.1, run locally), they agree to within 7.3·10−15 relative error, the largest gap being at z = −10 in the far tail; mpmath is the more accurate of the two there. The extended validation table (38 points, z from −37 to 8) uses the same mpmath procedure and is not copied from the web.

1. Why Φ is not elementary (Liouville)

Liouville's theorem (Rosenlicht form). Let f, g be rational functions with g non-constant. Then ∫ f(x) eg(x) dx is an elementary function if and only if there is a rational function h with h′ + g′h = f; in that case the antiderivative is h·eg.

Application. Take f = 1, g = −x²/2, so g′ = −x and we need h′ − x·h = 1 with h rational. (i) If h had a pole of order k ≥ 1 at c, then h′ has a pole of order k+1 while x·h has order ≤ k: no cancellation is possible. So h is a polynomial of degree d. (ii) If h ≠ 0, x·h has degree d+1 and h′ has degree d−1, so the left side has degree d+1 ≥ 1, never the constant 1; if h = 0 the left side is 0 ≠ 1. Contradiction: e−x²/2 has no elementary antiderivative, hence neither Φ.

Remark. "No elementary antiderivative" is not "no antiderivative": Φ(z) = ½ + (1/√(2π)) Σ (−1)k z2k+1 / (2k k! (2k+1)) is an explicit antiderivative as a power series. Also the definite integral over ℝ equals 1 (polar coordinates) although no elementary antiderivative exists.

2. The error function

erf(x) = (2/√π) ∫0x e−t² dt is defined to be that antiderivative, and then Φ(z) = ½ [1 + erf(z/√2)] exactly, i.e. an exact analytic representation. But it only moves the problem: erf is a new special (non-elementary) function whose values are known in closed form only at 0 and ±∞. To get a number one still needs an algorithm: quadrature, a series, a continued fraction or a rational approximation. That is why libraries ship such routines (C has erf/erfc; JavaScript's Math has no erf at all, so it is implemented below).

3. Implemented methods

  • Trapezoid and Simpson (n = 100 panels): Φ(z) = ½ + ∫0z φ. Errors O(h²) and O(h⁴).
  • Maclaurin series (from the course notes): alternating, up to 200 terms; terms reach ≈ ez²/2, so cancellation destroys digits for large |z|.
  • A&S 7.1.26: erf(x) ≈ 1 − (a₁t+…+a₅t⁵)e−x², t = 1/(1+px); absolute error ≤ 1.5·10⁻⁷, five multiplications, one exp.
  • erf positive series (Kummer): Φ(z) = ½ + φ(z) Σ z2n+1/(1·3·5…(2n+1)). All terms positive for z > 0, no cancellation inside the sum.
  • Hybrid: positive series for |z| < 2, otherwise the continued fraction Q(z) = φ(z) / (z + 1/(z + 2/(z + 3/(z + …)))) evaluated for the tail directly, so Φ(−z) = Q(z) keeps full relative precision and 1 − Φ is never formed.

4. Conclusions

Accuracy. Quadrature from 0 to z is accurate for moderate z but computes ½ + (small tail integral) for negative z, so relative accuracy in the lower tail is lost (Φ(−5) ≈ 2.9·10⁻⁷, Φ(−10) ≈ 7.6·10⁻²⁴). The alternating Maclaurin series suffers catastrophic cancellation at |z| ≥ ~4. A&S 7.1.26 is only 10⁻⁷ accurate in absolute terms, hence useless in tails. The positive series is accurate near the centre but, for negative z, computing ½ − (…) has the same tail problem. The hybrid is accurate to a few units of 10−15 relative error for most z; on a dense grid of 1601 points in [−8, 8] (step 0.01) checked against mpmath the worst case was 7.9·10−15, which grows slowly with |z| because of the rounding error in exp(−z²/2). The switch point matters: with the series used up to |z| < 3 the worst case was 1.2·10−13 (near z = −2.97, where ½ − φ(z)·Σ loses about two digits to cancellation), so the series is used only for |z| < 2.

Efficiency. Quadrature costs O(n) exp evaluations per call; the series needs about |z|² + 20 terms and the continued fraction a fixed ≈ 200 steps with no exp inside the loop; A&S needs a single exp and is the fastest. Convergence is geometric for the series (factor z²/(2n+1) per term once n > z²/2), algebraic for trapezoid/Simpson (error table above).
